# Triage log: spec NNN

The author records a decision for **every** reviewer finding, every round. The reviewers read this file
on the next round, so a rejection with a clear reason stops the same point coming back.

Decisions: **fixed** (with commit) · **rejected** (reason: cite the spec or the code) · **ask-human** (spec is silent or ambiguous) · **deferred** (the user agreed to a follow-up)
